📡 LLM Radar

Privacy Policy

Last updated: April 30, 2026

Summary

LLM Radar stores all data locally in your browser only. No data is sent to any external server. We collect nothing about you personally.

What We Collect

  • LLM API call metadata: model name, provider, token counts, latency, estimated cost
  • First 500 characters of prompts sent to LLM APIs
  • First 500 characters of LLM responses
  • Timestamps of API calls

What We Do NOT Collect

  • Personal identifying information of any kind
  • Full prompt or response content beyond 500-character previews
  • Browsing history unrelated to LLM API calls
  • Cookies, credentials, or authentication tokens
  • Any data from non-LLM websites

Data Storage

All captured data is stored locally using chrome.storage.local — it never leaves your device. If you enable Forward to local server in Settings, data is sent only to localhost or 127.0.0.1 (a server running on your own machine).

Data Sharing

We do not sell, share, or transmit your data to any third party. Ever.

Data Retention

Data is retained until you click Clear in the popup or uninstall the extension. Maximum 500 calls stored at any time.
